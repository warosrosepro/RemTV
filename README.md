RemTV — настраиваемый лаунчер для телевизоров и ТВ-приставок на Android. Он объединяет два режима домашнего экрана — **Night Scenes** и **Classic** — с персонализируемым доком, быстрыми системными инструментами и управлением с обычного телевизионного пульта.

Проект написан на Java и использует Android SDK. Для сборки предусмотрены скрипты Windows и macOS/Linux; Gradle не требуется.

## Возможности

### Домашний экран и персонализация
- **Night Scenes** — фоновые сцены, часы, дата, приветствие и погода.
- **Classic** — сетка приложений и центральный док в стиле tvOS.
- **Liquid Glass Dock** — настройка размера и порядка приложений, папка Other Apps.
- Пользовательские обои, несколько слотов и случайная смена изображений из выбранной папки.
- Изменение названий и иконок приложений, скрытие приложений и пользовательские профили.

### Управление телевизором
- Панель быстрых настроек поверх домашнего экрана и других приложений.
- Переключатель недавних приложений и просмотр использования RAM.
- **Button Mapper** — действия на одиночное, двойное и тройное нажатие кнопок пульта.
- Дополнительные действия для кнопок, включая отправку Android KeyEvent.
- Настраиваемые функции сна, Ambient Mode и встроенный экран блокировки.

### Контент и повседневные функции
- **Continue Watching** на основе данных, предоставляемых медиаприложениями и системными службами Android TV.
- Поиск приложений и контента, рекомендации и новостная лента.
- Погода с прогнозом на несколько дней.
- Несколько пользовательских профилей.

### Инструменты и обслуживание
- Первоначальная настройка и помощник выдачи разрешений.
- Secure ADB Mode и Persistent ADB Mode.
- **CleanYourTV (Beta)** — профили для моделей ТВ, управление системными лаунчерами и системными приложениями.
- Проверка обновлений и установка APK из интерфейса лаунчера.
- Резервное копирование и восстановление настроек.

### Языки
Интерфейс включает русский, английский, турецкий, шведский, хинди, испанский, французский, немецкий, итальянский, португальский, арабский, японский, китайский и корейский языки.

## Совместимость

- **Android TV / Google TV:** Android 7.0 (API 24) и новее.
- Интерфейс рассчитан на управление с телевизионного пульта (DPAD).
- Доступность отдельных функций зависит от производителя, версии Android и системных служб устройства.
- Некоторые расширенные возможности требуют специальных разрешений или настройки через ADB.

## Установка

Когда сопровождающий проекта опубликует релиз, APK можно будет скачать в разделе **[Releases](../../releases)**.

1. Скачайте APK из Releases.
2. Установите его на Android TV или Google TV.
3. Запустите RemTV и пройдите первоначальную настройку.
4. Следуйте подсказкам, чтобы назначить RemTV домашним экраном.

Если релизов пока нет, соберите APK из исходников по инструкции ниже.

## Сборка из исходников

### Требования
- JDK 17 или новее.
- Android SDK.
- `platforms;android-34`.
- `build-tools;34.0.0`.

При необходимости укажите переменные окружения `JAVA_HOME` и `ANDROID_HOME` (или `ANDROID_SDK_ROOT`).

**Windows (PowerShell):**
```powershell
powershell -ExecutionPolicy Bypass -File .\build.ps1
```

**macOS / Linux:**
```bash
chmod +x ./build.sh
./build.sh
```

После успешной сборки APK появится в `build/RemTV.apk`.

Установка через ADB:
```bash
adb connect <IP-адрес-телевизора>:5555
adb install -r build/RemTV.apk
```

Доступность сетевого ADB зависит от устройства и настроек разработчика. Не оставляйте ADB включённым без необходимости.

## Безопасность

- Выдавайте только те разрешения, которые нужны используемым функциям.
- Перед использованием CleanYourTV внимательно проверяйте список пакетов: отключение системных компонентов может нарушить работу отдельных функций телевизора.
- Secure ADB Mode предназначен для выдачи необходимых разрешений при настройке с последующим отключением сетевого ADB.
- **Не публикуйте keystore, пароли, токены и другие секреты.** Ключ подписи релизной версии должен храниться отдельно от публичного репозитория.
- Не используйте ADB через недоверенные сети.
